# Michał & Paulina - Aplikacja z Synchronizacją

Piękna strona z historią Michała i Pauliny, rozszerzona o automatyczną synchronizację między urządzeniami.

## 🚀 Uruchomienie

```bash
npm start
```

Otwórz przeglądarkę: `http://localhost:3000`

## 📱 Synchronizacja między urządzeniami

Zaloguj się tym samym kontem na różnych urządzeniach (telefon, komputer, tablet) - wszystko będzie automatycznie synchronizowane w czasie rzeczywistym:

- 💬 Wiadomości na czacie
- 📷 Zdjęcia
- 👥 Użytkownicy i grupy
- 🎮 Gry i wyniki
- ⚙️ Ustawienia

## 📲 Testowanie na telefonie

1. Sprawdź IP komputera: `ifconfig` (Linux/Mac) lub `ipconfig` (Windows)
2. Na telefonie wejdź na: `http://[twoje-ip]:3000`
3. Zaloguj się tym samym kontem co na komputerze
4. Wszystko działa w czasie rzeczywistym! ✨
